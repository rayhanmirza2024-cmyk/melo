# Mealio

Mealio is a small Next.js app for tracking lunch/dinner meals per day and generating a monthly PDF report.

## Included sample
- February 2026 seeded data with only `2026-02-27` dinner set to true.
- Meal price defaults to `৳50`.

## Run
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
